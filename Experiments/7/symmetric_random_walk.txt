SYMMETRIC RANDOM WALK
=====================

1. WHAT IS IT
-------------
A dataset of 64x64 grayscale images of random-walk paths that have been
mirrored across the vertical centre axis.  Each image resembles a
Rorschach inkblot: organic and unpredictable in detail, yet possessing
perfect bilateral symmetry.  This makes the dataset interesting because
the symmetry is deterministic while the content is stochastic.


2. GENERATION ALGORITHM
-----------------------
For each image:

  1. Let  cx = size // 2  be the axis of symmetry.
     Start the walk at (cx, size//2) — the image centre.

  2. Randomise the walk parameters:
       - step_size   in  [1.5, 3.0]
       - num_steps   in  [80, 200]

  3. Perform a biased random walk on the right half of the image:

       For each step:
         a. Sample a random angle:
                theta  in  [-pi/2,  pi/2]
            (angles in this range always have a non-negative x-component,
             so the walk is biased to stay on the right side.)

         b. Compute the displacement:
                dx = step_size * cos(theta)
                dy = step_size * sin(theta)

         c. Update the position with boundary clamping:
                x <- clamp( x + dx,  cx,  size-1 )
                y <- clamp( y + dy,  0,   size-1 )

         d. Append (x, y) to the right-side path.

  4. Create the left-side path by reflecting every point:
         (x, y)  ->  (2*cx - x,  y)

  5. Draw both polylines (white on black).


3. MATHEMATICAL BACKGROUND
---------------------------
Symmetry group:  Z2  (cyclic group of order 2, generated by the
                       vertical reflection  sigma: x -> 2*cx - x)

The construction enforces exact bilateral symmetry by definition:
the left half is a deterministic function (reflection) of the right half.

Random walks:  In the unbiased case, a 2D random walk on a lattice
returns to the origin with probability 1 (Polya's recurrence theorem),
though the expected return time is infinite.  Our walk is biased (drift
to the right) and operates in continuous space, so it does not recur;
instead, it explores the right half-plane.

The angular distribution  theta ~ Uniform(-pi/2, pi/2)  gives expected
displacement per step:

    E[dx] = step_size * E[cos(theta)]
          = step_size * (1/pi) * integral_{-pi/2}^{pi/2} cos(theta) d(theta)
          = step_size * 2/pi
          ~ 0.637 * step_size

    E[dy] = 0   (by symmetry of sin on [-pi/2, pi/2])

So the walk has a rightward drift of approximately 0.637 * step_size
per step and zero vertical drift.

The variance of dy per step is:
    Var[dy] = step_size^2 * E[sin^2(theta)]
            = step_size^2 * 1/2

So the vertical spread after N steps grows as  ~ step_size * sqrt(N/2).

Clamping at the boundaries introduces a reflecting barrier, which biases
the long-run distribution toward the centre of the right half.

The resulting images live on a high-dimensional stochastic manifold.
Unlike the other datasets in this collection, the "shape" of each image
is not governed by a low-dimensional parameter vector but by the full
sequence of random angles — making the intrinsic dimensionality of this
dataset much higher (proportional to num_steps).
