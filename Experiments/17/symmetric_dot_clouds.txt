SYMMETRIC DOT CLOUDS
====================

1. WHAT IS IT
-------------
A dataset of 64x64 grayscale images containing scattered filled circles
(dots) arranged with D_n dihedral symmetry.  Random dots are placed in a
single fundamental wedge and then replicated by n rotations and n
reflections, producing intricate radially-symmetric point patterns.


2. GENERATION ALGORITHM
-----------------------
For each image:

  1. Place the centre at (cx, cy) = (size/2, size/2).

  2. Randomise:
       - fold  (n)    from  {3, 4, 5, 6, 8}
       - num_dots     in  {8, ..., 30}
       - dot_r        in  [1.0, 2.5]   (dot radius in pixels)

  3. For each base dot, sample a random position in the fundamental
     wedge  [0, pi/fold]  using polar coordinates:
         r  in  [3, size/2 - 3]
         a  in  [0, pi/fold]

  4. Replicate each dot by the dihedral group D_n:
       For k = 0, 1, ..., fold-1:
         For mirror in {+1, -1}:
           angle = mirror * a  +  k * 2*pi/fold
           (dx, dy) = (cx + r*cos(angle),  cy + r*sin(angle))
           Draw a filled circle of radius dot_r at (dx, dy).


3. MATHEMATICAL BACKGROUND
---------------------------
Symmetry group:  D_n  (dihedral group of order 2n)

D_n is generated by a rotation  R = 2*pi/n  and a single reflection s:
    D_n = { R^k,  s*R^k  |  k = 0, 1, ..., n-1 }

The fundamental domain is a wedge of angular width  pi/n,  which is
half the width of the C_n fundamental domain (pi/n vs. 2*pi/n) because
reflections halve the fundamental domain.

Each base dot generates an orbit of size:
  - 2n  for a generic point (not on a symmetry axis)
  - n   for a point on a mirror axis  (stabiliser of order 2)
  - 1   for the centre point  (stabiliser = D_n)

With k base dots, the total number of rendered dots is at most  2*n*k,
giving images with between  24  and  480  visible dots.

The discrete, scattered nature of the pattern makes this dataset
qualitatively different from the smooth curves in most other experiments.
An autoencoder must learn to represent the positions of individual
dots while respecting the symmetry constraints.

Parameter space:  (n, num_dots, dot_r, {r_j, a_j}_{j=1..num_dots})
— a high-dimensional space (2 * num_dots + 3 parameters), partitioned
into 5 symmetry classes by the discrete choice of fold number.
